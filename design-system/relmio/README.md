# Historical design record

The files in this folder record earlier Relmio design directions (Signal Plotter,
Doorway Playground and the Hallmark redesign). They are kept for history and are
superseded by [DESIGN.md](../../DESIGN.md) and [BRANDKIT.md](../../BRANDKIT.md).
Do not use them as current rules.

The images in `assets/` remain the art direction sources referenced by BRANDKIT.md.
