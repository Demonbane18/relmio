# Relmio public redesign checklist

This checklist tracks the authorized local redesign. A passing build alone does
not establish visual acceptance. Nothing is deployed, released, or committed.

## Approved copy

**Headline:** Bring your AI sign-ins to your tools.

**Supporting line:** Keep every credential where it belongs. Relmio guides you
through sign-in and setup for n8n and local tools.

This supersedes the earlier proposed headline, following the user's preference
for a provider-neutral adaptation of the GitHub tagline.

The hero does not carry provider-specific release notes. The connection guide
retains accurate availability and limitations for each route.

## Hallmark audit scope

Lead scores: **P4 H4 E4 S4 R3 V4**. The relay journey gives the artwork a product
purpose, the heading and sole install CTA establish hierarchy, and the original
mascot anchors the page. Retained detailed connection guidance is intentionally
secondary and more utilitarian. The final visual verdict remains subjective.

Independent scores match the lead: **P4 H4 E4 S4 R3 V4**.
The 58-gate reference was reviewed against the new hero and changed page chrome.
This is not a blanket 58/58 certification of the pre-existing chat and guide.
The playful-canvas exception applies to the centered invitation (gate 6).
The user's explicit request for a colorful cartoon world takes precedence over
an arbitrary 5% illustration-color limit (gate 23); landscape, sun, clouds and
flowers belong to that illustrated world rather than adding false product facts
(gate 45). Existing truthful guide content and operational controls remain.
The user's explicit request to keep all header links and theme/GitHub controls
takes precedence over a generic navigation-minimization preference (gate 42).

The headline uses roman Bricolage, the body uses Geist, and existing code labels
use Geist Mono. No new gradient text, fabricated metrics, fake browser chrome,
Lottie dependency, or redrawn Relmio logo was introduced. New colors/fonts are
scoped named tokens. Page-edge clipping is applied to homepage html and body.

Rendered hero contrast ratios (light / dark): headline 11.99 / 14.62,
supporting text 5.78 / 7.69, install button 7.06 / 5.51, pause control
12.59 / 14.28, caption 5.78 / 7.69. Measurements composite computed CSS colors
through ancestor backgrounds using the browser's canvas conversion. Disabled
