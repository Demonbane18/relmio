# Documentation: Field Manual

- Shared shell and tokens, but optimize for reading rather than spectacle.
- A slim persistent table of contents may appear at desktop widths; on mobile use native disclosure/navigation.
- Use mono route labels and small topology diagrams only when they clarify boundaries.
- Commands use the same black terminal component as Install.
- Maximum prose width 72ch; headings and anchors must remain reachable behind sticky navigation.
