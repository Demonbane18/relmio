# Home: Doorway Playground

The current public direction is governed by `../../../DESIGN.md` and Hallmark.
It supersedes the former split headline and connection-map hero.

- Lead with a short, plain invitation and one clear install action. Compose a
  broad illustrated doorway world into the page; avoid a framed picture beside
  a technical introduction.
- Preserve the original logo artwork and proportions. Build the playful vector
  environment around that identity, using the public design system's upright
  display type, cream canvas, pine ink, teal anchor, and named illustration colors.
- Use one coordinated visible scene loop, a pause/resume control, immediate
  reduced-motion support, and offscreen pausing. The static state must be complete.
- Keep the interactive connection map and all five real options in a secondary
  accessible guide. Each selected option explains its origin, authentication,
  connection, destination, and actual availability.
- Vary the rhythm through illustration, concise explanation, the practical guide,
  and a useful closing invitation. Avoid repeated equal feature cards and invented
  testimonials, metrics, or availability claims.
- Preserve hosted chat, all existing destinations, and the practical installer.
  The header retains How it works, Install, Docs, Changelog, Chat, GitHub,
  Support, and System/Light/Dark controls. Footer destinations may repeat the
  header links intentionally. Header groups wrap in DOM order at narrow widths.
  Verify the public page in Opera GX at 320, 375, 414, 768 px and desktop in both
  themes, including keyboard, touch, zoom, pause, and reduced-motion behavior.

logo asset. Keep three purposeful stops (VPS cloud, Relmio, local workshop), no smiling

and a lit workshop window, preserving the mascot and architecture colors.

eyes and quiet Zzz in night mode. Day mode restores the original blinking eyes.

obeys pause, reduced motion, visibility and unsupported-animation fallback.
