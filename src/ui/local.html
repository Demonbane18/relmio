      Connection details and limits

      ChatGPT for n8n is unofficial, private, and policy-uncertain. It copies the saved ChatGPT/Codex credential file into an openai-oauth sidecar on the shared Docker network and publishes no host port. That file is not identity-only sign-in and not a Platform API key. Availability depends on your account. Supported here: Message a Model, and GPT Image generation or editing. Unavailable through this bridge: audio, TTS, moderation, file management, and stored conversations. Use a separate OpenAI Platform connection for those supported actions. Never enter that API key here. Video is separate: OpenAI shut down the Videos API on September 24, 2026, with no replacement listed. Codex may write a login log. Relmio does not know how long the pinned runtime keeps it.

      Grok for n8n uses official SuperGrok sign-in only. It adds a private Chat Completions companion. No provider token or API key is entered here.

      Codex App Server is an experimental JSON-RPC WebSocket for a trusted native app. It is not OpenAI /v1. Browsers cannot connect directly.

      Codex Chat Adapter is an experimental POST /chat endpoint for a trusted local backend. It is not /v1. Do not put it in browser code.

      n8n AI Assistant tools add a private Code Sandbox and optional SearXNG search. The sandbox runner is privileged and host-root equivalent. For production, use Daytona. Relmio does not edit or restart n8n.

      Local model for n8n publishes no host port. Other containers on its network can use the model API without a password. Relmio checks free memory and disk before download. CPU answers can be slow. There is no cloud fallback.

      Set up new n8n creates a separate stack. The public link requires Basic Auth. Existing n8n is not changed.

      Step 3 of 4 · Install

      Install

      Install the reviewed connection. Provider sign-in happens after, inside its own runtime.

      High-trust local key

      Anyone with this key can control Codex in its container, act through your ChatGPT sign-in, and may recover that container's ChatGPT session. Treat it like your ChatGPT password. Give it only to a trusted local app.

      Unofficial private bridge

      Relmio copies the saved ChatGPT/Codex credential file into its private volume and starts only the new sidecar. It will not change n8n, publish port 10531, or install Code Sandbox or SearXNG. This is not identity-only sign-in and not a Platform API key. Unofficial and policy-uncertain.

      Privileged testing companion

      Relmio starts only its Code Sandbox services and the SearXNG option you chose. The runner is privileged Docker-in-Docker and host-root equivalent. It will not change n8n. Copy the returned settings into n8n yourself. For production, use Daytona.

      Public link needs Basic Auth

      Paste one ngrok agent token, not the ngrok config add-authtoken ... command and not an ngrok API key. Create the Basic Auth username and password here. They do not come from ngrok, n8n, Relmio, Windows, or ChatGPT. Save them. Relmio clears them after you submit and does not show them again.

      Create and save this password yourself. Use 12–512 characters with no colon or line breaks.
