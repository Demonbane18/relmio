Set up a new local n8n stack

Reviewing only checks local Docker. It creates nothing and does not expose ngrok.

Set up ngrok in three steps
  1. Create or choose a static ngrok domain in the ngrok dashboard.
  2. Copy an active agent token from Your Authtoken. “Your Authtoken” is the quick-copy page; “Authtokens” is the page that lists and manages tokens. They are the same credential type, and the token must be allowed to use your reserved domain.
  3. Choose a separate Basic Auth username and strong password for people opening this n8n link.

After installation, open the public link in a private browser window. It must stay blocked until you enter that Basic Auth pair.

Uses an OpenAI Platform API key

Your key is seeded over stdin into a private Docker volume and is never returned to the browser. A separate local client credential is generated for your apps.

Step 3 of 4 · Install

Install the local container

Enter the OpenAI Platform API key that this endpoint will use upstream. It is sent only to this local Relmio process.

High-trust capability

Anyone holding the generated client credential can control Codex inside its isolated container, act through your signed-in ChatGPT session, and may be able to recover that container's ChatGPT session credential. Treat this capability like your ChatGPT password and give it only to a trusted native local app.

Unofficial private bridge

Relmio will seed its private managed volume from your local ChatGPT OAuth credential and start only the new sidecar. It will not change or restart n8n, publish port 10531, or install Code Sandbox or SearXNG.

Privileged local testing companion

Relmio will start only its ownership-bound Code Sandbox services and optional SearXNG container. It will not edit, exec into, rebuild, restart, stop, recreate, or change network membership on n8n. Apply the returned n8n settings yourself after installation.

Public endpoint, mandatory Basic Auth

“Your Authtoken” is ngrok’s quick-copy page and “Authtokens” is its token-management page; both provide the same type of agent credential. Paste only one active agent token value—not the ngrok config add-authtoken ... command and not an ngrok API key. Create the Basic Auth username and password yourself here; they do not come from ngrok, n8n, Relmio, Windows, or your ChatGPT sign-in. Save them in your password manager because people opening the public n8n link will need them. Relmio clears all three values from the browser after submission and never shows them in results or errors.

Create and save this password yourself. Use 12–512 characters with no colon or line breaks.
