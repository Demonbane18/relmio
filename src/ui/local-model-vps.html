About the server check

The check reads Docker Engine, Compose, the local endpoint, the admin account, an existing /docker directory, running official n8n, a private network, memory and disk. Relmio does not install or upgrade Docker or n8n.

About SSH agent sign-in

Load keys into your local agent before you open Relmio. A persistent dashboard keeps its launch environment, so relaunch it after you change the agent. Relmio does not read private-key files, ask for passphrases or forward your agent.
