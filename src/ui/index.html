More details about this connection

This uses a saved ChatGPT/Codex credential, not just your identity and not a Platform API key. Ordinary ChatGPT sign-in for a supported app shares your name, email, and an optional picture. This route copies the credential file only after you approve that upload.

What you can use depends on your account. This bridge supports Message a Model and GPT Image generation or editing. It does not support audio, text-to-speech, moderation, file management, stored conversations, or video. Use a separate OpenAI Platform connection for supported audio, moderation, file management, and stored conversations. Do not enter that API key here. OpenAI shut down the Videos API on September 24, 2026, with no replacement listed. A listed model is not proof that a workflow works.

The OpenAI bridge remains unofficial, private, and policy-uncertain. OpenAI still processes later model requests. Log retention for this pinned Codex login is not known. Approval here is for the Relmio upload, not an OpenAI permission.
