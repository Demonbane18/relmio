    Open the Codex sign-in page (opens in a new tab)

    Models marked In n8n show up in n8n's OpenAI nodes. Relmio asks OpenAI's catalog as the newest Codex release, checked from npm about every 12 hours.

    When on, the sidecar sends one short test request ('Reply with OK') to models in your catalog: now for up to 12 of them, then for each new model, and again once a day for a model that failed. A test that gets no answer is tried again after an hour. n8n lists a model only after it answers; until any model has answered, n8n shows the full catalog except models that recently failed. Each test uses a small amount of your plan.

    n8n's AI Assistant can't list these models. To try one, choose Self-hosted or OpenAI-compatible endpoint in its settings, use the Base URL http://n8n-openai-oauth:10531/v1 with the same Relmio key as your n8n OpenAI credential, and paste a model ID. Only do this if nobody else uses this n8n: their Assistant chats would use your ChatGPT plan. Relmio hasn't tested the Assistant with this sidecar, and OpenAI hasn't said whether this use fits its Sign in with ChatGPT terms.
