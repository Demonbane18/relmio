Connect n8n to SuperGrok

In an OpenAI credential, set the Base URL to http://n8n-supergrok:14502/v1. Use the local bridge bearer below in its API-key field.

The newly generated bearer is shown only in this browser session. Save it directly in your n8n credential. For an existing installation, enter its saved local bearer to check models.

Use Chat Completions. Turn off “Use Responses API” in the workflow OpenAI Chat Model and Chat Hub's OpenAI provider settings. Choose a model from your account's returned list.

For Assistant, use the same URL, bearer and a text model ID. Its sandbox is a separate companion. Relmio does not switch your existing n8n provider settings.
