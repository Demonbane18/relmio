# Relmio localhost wizard surface

- Scope and mode: replace the visual world of the five-step local browser
  wizard; Operate.
- Audience and job: a non-technical VPS owner must sign in, verify the SSH host,
  choose the detected n8n target, review the exact sidecar plan, explicitly
  approve remote writes, and copy the final settings.
- Chosen direction: Patchbay Ledger, seed `c4426c7c`. Use the same routing
  grammar at higher density and lower motion, with each workflow boundary
  presented as a connected checkpoint rather than decorative machinery.
- Memorable moment: progress shows a private route becoming verified one gate
  at a time, while the current task remains the dominant element.
- Constraints: preserve every form name, DOM ID, keyboard behavior, status and
  error state, textContent-only rendering boundary, host-key confirmation, and
  final write confirmation. No React or build dependency may be added to the
  published CLI wizard.
- Composition: inherit the approved Signal Spine grammar from
  `.impeccable/mocks/signal-spine.png`, then optimize it for operation rather
  than persuasion.

## Approved-comp implementation inventory

| Visible ingredient | Wizard translation | Medium |
| --- | --- | --- |
| Signal spine | Five persistent checkpoints become verified one gate at a time | Semantic ordered list, existing state model, CSS connector geometry |
| Narrative rail | Compact setup context, current safety boundary, and progress remain visible on wide screens | Semantic aside; responsive CSS grid |
| Active work surface | One dominant form or review panel with dense labels and familiar controls | Existing HTML forms and IDs; Astryx-aligned CSS tokens |
| Safety ledger | Contextual host, network, write, and secret boundaries appear beside the relevant action | Status regions and definition lists; textContent-only updates |
| Completion route | Final endpoint and copyable settings read as the completed signal path | Existing result fields and copy buttons; semantic HTML |
| Material character | Warm canvas, graphite seams, relay teal, restrained corners, quiet dark mode | Dependency-free CSS custom properties |

The local wizard does not import React or Astryx runtime code. It carries the
same tokens, rhythm, control states, and route vocabulary in static HTML/CSS so
the published CLI stays small and fast.
