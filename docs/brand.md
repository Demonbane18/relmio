# Relmio brand

Relmio is the public project name. Older remote paths, Docker names, marker
files, and credential paths keep `n8n-openai-oauth` for compatibility.

![Relmio logo](images/brand/relmio-logo.png)

The 512-pixel PNG is the main logo and icon: a teal two-eyed character in a
cream doorway on a sage square. Use the checked-in file in the README, hosted
app, and local wizard. Do not crop, stretch, recolor, outline, rotate, or
recreate it.

The animated banner is a wordless loop drawn from the same mascot and doorway.
The mascot has two eyes and no mouth, and its doorway stays a separate shape.

The complete brand kit, with logo rules, colors, typography, icons and voice,
is [BRANDKIT.md](https://github.com/Demonbane18/relmio/blob/main/BRANDKIT.md).
Interface rules for the local wizard and the website are in
[DESIGN.md](https://github.com/Demonbane18/relmio/blob/main/DESIGN.md).
