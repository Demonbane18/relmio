# Relmio brand

Relmio is the public project name. Older remote paths, Docker names, marker
files, and credential paths keep `n8n-openai-oauth` for compatibility.

## Logo and icon

![Relmio gateway android logo](images/brand/relmio-logo.png)

The 512-pixel PNG is the main logo and icon. Use the checked-in file in
the README, hosted app, and local wizard. Keep it square with its moss
background. Do not crop, stretch, recolor, outline, rotate, or recreate it.

## Animated banner

The public banner is a wordless, hand-drawn loop. The green two-eyed figure is
the Relmio mascot. It has no mouth. The cream arch is its doorway and stays
separate from the mascot.

Imagegen produced the visual study at
`design-system/relmio/assets/relmio-banner-imagegen-source.png`. The shipped SVG
uses that study as art direction, then draws the original mascot and doorway as
separate vectors so the logo stays recognizable at every frame.
